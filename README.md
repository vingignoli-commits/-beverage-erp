# Beverage ERP

ERP NAVEGANTE - Gestión de empresa productora y comercializadora de bebidas.

## Stack base
- Next.js
- TypeScript
- Tailwind
- Prisma
- PostgreSQL (Neon)
- Vercel
- Render
- Cloudflare R2

## Objetivo
Centralizar operación comercial, productiva, financiera y de control en una sola app.

1. Base técnica
2. Auth y roles
3. Clientes y proveedores
4. Productos e insumos
5. Pedidos y pagos
6. Inventario
7. Producción
8. Reportes y automatizaciones
